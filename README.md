# 指路互動地圖 · Vamos pela cidade!

線上白板版：<https://jinnamcyber.github.io/pela-cidade/>

GitHub Pages 提供直接操作及舉手／ABC 卡投票。手機連線投票需下載整個專案，在老師電腦啟動本機 Node.js 伺服器，再讓學生連同一個網絡。

SG3 U7 電子白板指路活動，採用 ImageGen 立體微縮城市、透明旅人人物和 A/B/C 指令牌。

上方可以切換兩張地圖：**城市探險**有十二個內街街區、四條新增支路、住宅和商店；**練習地圖**保留原本三橫三直街道，供對照今日的紙本練習。兩張地圖都保留十個主要目的地。切換地圖會返回起點，並關閉當前投票。

## 白板即用

雙擊 **指路互動地圖.html**，用 Chrome 或 Edge 開啟。一個檔案就可以，毋須網絡。

1. 選地圖，再選目的地，或點地圖上的地標名稱。旅人每次由 Partida 面向上方出發。
2. 學生先講葡文，再按 **A 左轉、B 前進、C 右轉**。
3. 左右轉只在原地轉 90°；前進會行到下一個路口或路盡頭。左右跟人物面向。
4. 可撤回一步、返回起點、隨機選目的地，或選「自由探索」。

鍵盤：←／↑／→ 或 A／B／C。全螢幕按右上角按鈕。

## 舉手／ABC 卡投票

切到「全班投票」。學生舉手或舉卡，老師輸入 A、B、C 票數，再按「確認票數，執行指令」。
同票或未有票數時人物不動；清空票數再投。

## 手機／平板投票

1. 老師電腦需要 Node.js；Mac 雙擊 **啟動手機投票.command**。亦可在此資料夾執行 `node server.js`。
2. 保持終端機視窗開啟。Mac 會自動開老師控制頁；其他系統可複製終端機的老師網址到瀏覽器。
3. 學生裝置與老師電腦連同一個網絡。老師按「學生加入」，分享其中一個學生網址；多個網址時選課堂 Wi-Fi 對應的地址。
4. 老師切到「裝置投票」，按「開始新一輪投票」。學生在自己畫面揀 A／B／C。
5. 老師按「截止投票，執行勝出指令」。同票或零票會結束該輪而不移動；按「開始新一輪投票」重投。

每個瀏覽器用 cookie 保留一票，截止前可改票；共用一個瀏覽器的同學會共用一票。這是課堂投票，沒有學生身分驗證，請勿用無痕視窗或清除 cookie 重複加入。學生頁不收集姓名。

老師變更目的地、返回起點、撤回或切換模式時，會關閉當前一輪。已截止的票不會帶入下一輪。
關閉伺服器後路線和票數不保留；重開後請使用新的加入網址。老師控制頁網址只供老師使用。

若 Windows 防火牆詢問，須允許課堂網絡連線。若學校 Wi-Fi 隔離裝置，可用同一個熱點或改用舉手投票。若連接埠 8765 已使用，可執行 `MAPA_PORT=8766 node server.js`（Mac/Linux）。

## 修改與驗證

改 `src/` 後執行 `python3 build.py`，會同時產生離線單檔 `指路互動地圖.html` 及 GitHub Pages 入口 `index.html`。網站入口以相對路徑載入 `assets/` 的三個美術素材。不要只改輸出的 HTML，重新建立時會被覆蓋。

網站以 `main` 分支根目錄作為 GitHub Pages 發佈來源。更新時重新建立、提交並推送 `main`；等 Pages 部署完成後驗證網站。

```sh
node --test tests/classroom.test.cjs
node tests/browser.cjs  # 需要 playwright 與 Chromium；可用 PLAYWRIGHT_MODULE_PATH 指定套件路徑
```
